GOOD TO KNOW

Frequently asked questions.

What is ServerHub? +

ServerHub is a marketplace concept that brings server packages from independent providers into one place to discover and compare.

Are the listings and checkout live? +

This preview runs in demo mode. Listings are sample data, and checkout creates a local demo order only. No payment is processed and no server is provisioned.

Can I deploy a GitHub repository? +

You can try the deployment flow using a repository URL, but this demo does not connect to GitHub or run a real build. Never enter private keys or production secrets here.

Does my information persist? +

Demo account details, rental orders, and deployment records are saved in this browser’s local storage. They are not securely authenticated or synced to a database.
